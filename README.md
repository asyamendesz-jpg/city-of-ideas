# city-of-ideas
«Город идей» — браузерная бродилка с головоломками. Выбери героя, обойди квартал и преврати пустой домик в своё дело. Узнай, чем оно отличается от соседних, собери маршрут из карточек и проведи по нему первого посетителя. Открой дом, сохрани чертёж, поделись им или напиши Асе Мельниковой, чтобы обсудить разработку сайта, приложения или интерактива.
